# limen

Typed decisions with an explicit threshold — act, abstain, or escalate.

A *limen* is the point at which a signal becomes detectable. Everything below it is
subliminal: present, but not acted on.

See the [README](https://github.com/OWNER/limen#readme) for the full API sketch, and
[Brand](brand.md) for logo and colour usage.

!!! warning "Alpha"
    Nothing here is implemented yet. The documented API is a design, not a contract.
